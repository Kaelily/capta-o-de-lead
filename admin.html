Sincronização em Nuvem em Tempo Real

Conecte com seu GitHub no Supabase para receber leads de qualquer celular instantaneamente!

🚀 Como conectar em 1 minuto com sua conta GitHub:

  1. Acesse supabase.com e clique em "Continue with GitHub".
  2. Crie um projeto gratuito e abra o menu SQL Editor.
  3. Cole o código SQL abaixo e clique em Run:
create table if not exists leads (
  id text primary key,
  timestamp timestamptz default now(),
  name text,
  company text,
  role text,
  whatsapp text,
  email text,
  segment text,
  "segmentLabel" text,
  revenue text,
  "revenueLabel" text,
  pains jsonb,
  "currentSystem" text,
  urgency text,
  score int,
  status text,
  "estimatedMonthlyLoss" text,
  "estimatedMonthlyHours" text
);
alter table leads enable row level security;
create policy "Public Read" on leads for select using (true);
create policy "Public Insert" on leads for insert with check (true);
